<h3> Aprendendo automação de cadastro de produtos utilizando Python</h3>

<p align="justify">
  Este é um projeto em Python realizado pela semana de tecnologia realizado pela Hashtag, onde o projeto irá cadastrad os produtos contidos em um arquivo csv de maneira automatizada utilizando as bibliotecas pyautogui e pandas
</p>


### Visão Geral

O proncipal objetivo é aprender os conceitos e aplicações do Python em projetos de automação, vendo a forma que o projeto se comporta conforme o projeto é executado, tendo um projeto que facilite o cadastro de vários produtos de maneira automatizada.

### Tecnologias Utilizadas

<h4>Python
  
✔️ Python: Linguagem geral programada

✔️ pyautogui: Lib para mapear e realizar as ações da automação

✔️ pandas: Lib para leitura e apresentação das tabelas contendo os produtos para cadastro
</h4>

### Pincipal Funcionalidade
***Automação de Cadastros:*** 
Automação para cadastras produtos contidos em um arquivo.
